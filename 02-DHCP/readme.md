# DHCP Labs

This folder contains my Cisco Packet Tracer labs focused on **Dynamic Host Configuration Protocol (DHCP)** as part of my CCNA 200-301 preparation.

The goal of these labs is to strengthen my understanding of how DHCP automates IP address assignment, simplifies network administration, and supports scalable network deployments. Through hands-on practice, I explore DHCP configuration, relay agents, multiple address pools, and common verification and troubleshooting techniques used in enterprise networks.

Each lab includes its own documentation explaining the objective, topology, configuration, and key concepts learned throughout the exercise.
