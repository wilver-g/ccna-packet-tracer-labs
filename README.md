# 🌐 CCNA Packet Tracer Labs

A structured collection of **Cisco Packet Tracer** labs completed while preparing for the **Cisco Certified Network Associate (CCNA 200-301)** certification.

This repository documents my hands-on journey through the CCNA curriculum, beginning with fundamental networking concepts and progressing toward a realistic **enterprise campus network** that integrates routing, switching, redundancy, security, and network services.

The objective of this project is not only to prepare for the CCNA exam, but also to build practical Cisco IOS configuration skills and demonstrate real-world network design principles.

# 📚 Lab Progression

The labs are organized in the order I studied them.

| Folder | Topics Covered |
|---------|----------------|
| **01-Routing** | Static Routing, Default Routes |
| **02-VLAN** | VLANs, Trunking, Inter-VLAN Routing |
| **03-DHCP** | DHCP Server Configuration, DHCP Relay (IP Helper) |
| **04-DNS** | DNS Configuration and Name Resolution |
| **05-NAT** | Static NAT, Dynamic NAT, PAT |
| **06-ACL** | Standard ACLs, Extended ACLs |
| **07-STP** | STP, Root Bridge Election |
| **08-EtherChannel** | LACP, PAgP, Layer 2 EtherChannel |
| **09-HSRP** | Gateway Redundancy and Load Sharing |
| **10-Layer2-Security** | Port Security, DHCP Snooping, Dynamic ARP Inspection |
| **11-SSH** | Secure Remote Device Management and VTY Access Control |
| **12-FINAL-LAB** | Enterprise Campus Network integrating multiple CCNA technologies |

# 🏢 Final Enterprise Lab

The repository concludes with a comprehensive enterprise campus network inspired by a real-world hospital deployment.

The final lab integrates many technologies learned throughout the repository, including:

- Three-tier Campus Architecture
- Core, Distribution, and Access Layers
- OSPF Dynamic Routing
- HSRP Gateway Redundancy
- Layer 2 EtherChannel
- Multiple VLANs (Employee, Guest, Voice, Management)
- Centralized DHCP Services
- SSH Management
- DHCP Relay (IP Helper)
- Layer 2 Security
- Voice VLAN & IP Telephony
- Enterprise Switching Design

Rather than configuring isolated features, this lab demonstrates how these technologies work together in a realistic production-style network.
