# DNS Labs

This folder contains my Cisco Packet Tracer labs focused on **Domain Name System (DNS)** concepts covered in the CCNA 200-301 certification.

The goal of these labs is to understand how DNS translates domain names into IP addresses, how it integrates with DHCP to simplify client configuration, and how to troubleshoot common DNS-related issues encountered in enterprise networks.

## Labs

### 01 - Basic DNS

Configured a DNS server to resolve a domain name to the IP address of a web server. Verified successful hostname resolution and web access using a domain name instead of an IP address.

**Topics Covered**
- DNS Server Configuration
- DNS A Records
- Hostname Resolution
- HTTP Web Server Access

---

### 02 - DNS + DHCP Integration

Configured a server to provide both DHCP and DNS services. Clients automatically received their IP configuration and DNS server information through DHCP, then successfully accessed web servers using domain names.

**Topics Covered**
- DHCP Configuration
- Automatic DNS Server Assignment
- DNS and DHCP Integration
- Client Verification
- Web Access Using Domain Names

---

### 03 - DNS Troubleshooting

Simulated common DNS-related issues found in enterprise environments and followed a structured troubleshooting methodology to restore connectivity.

**Troubleshooting Scenarios**
- Incorrect DNS Server Address
- Missing DNS Record
- DNS Service Disabled

---

## What I Learned

Through these labs, I gained hands-on experience configuring and troubleshooting DNS services in Cisco Packet Tracer. I reinforced how DNS works with DHCP to provide seamless client connectivity and developed a systematic approach to diagnosing hostname resolution issues commonly encountered in enterprise networks.
