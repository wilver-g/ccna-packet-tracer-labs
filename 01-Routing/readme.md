# Routing Labs

This folder contains my Cisco Packet Tracer labs focused on **routing technologies** covered in the CCNA 200-301 certification.

The goal of these labs is to strengthen my understanding of how routers make forwarding decisions, establish communication between different networks, and exchange routing information. Through hands-on practice, I explore both static and dynamic routing while learning how to verify and troubleshoot routing behavior in enterprise network environments.

## Topics

### Static Routing
- Static Routes
- Default Routes
- Floating Static Routes
- Route Verification and Troubleshooting

### OSPF
- Single-Area OSPF
- OSPF Neighbor Adjacencies
- Passive Interfaces
- Default Route Advertisement
- OSPF Verification and Troubleshooting

Each lab includes its own documentation explaining the objective, topology, configuration, verification steps, and key concepts learned throughout the exercise.
